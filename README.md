# control-microbiologico-python
# Sistema Automatizado de Auditoría Microbiológica y Control de Proveedores 🔬📊
[📄 Descargar mi Hoja de Vida (PDF)](CV_Juan_David_Ospino.pdf)

Este proyecto implementa una arquitectura de datos relacional mediante **SQL** y **Python (Pandas/NumPy)** para centralizar y automatizar el control de inocuidad en el laboratorio de alimentos.

## 🛠️ Tecnologías Utilizadas
* **Python** (Pandas, NumPy, Seaborn, Matplotlib)
* **SQL** (PostgreSQL / SQLite: Tablas relacionales, Vistas, Inner Joins)
* **Google Colab**

## 🚀 Logros del Proyecto
* **Limpieza de Datos:** Scripts para purgar datos nulos o duplicados en registros de planta.
* **Cálculo Científico:** Transformación automatizada a escala logarítmica ($\log_{10}$) con NumPy.
* **Arquitectura SQL:** Diseño de Vistas inteligentes (`VIEW`) para evaluación automatizada de proveedores.
* **Reportes Ejecutivos:** Gráficos horizontales con Seaborn listos para comités de calidad.
